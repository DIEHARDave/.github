# Support

## Getting help

- **Bugs and feature requests:** open an issue in the repository for the project.
  Include your printer model, firmware (for example Zmod or stock version) and the
  relevant part of the log, not the whole file.
- **Questions:** use the repository's Discussions tab if it is enabled; otherwise open an issue.

These are hobby projects maintained in my spare time, so replies may take a few days.

## Supporting the projects

If a project saved you time or a failed print, you can help keep them going:

- [GitHub Sponsors](https://github.com/sponsors/DIEHARDave)
- [Ko-fi](https://ko-fi.com/DIEHARDave)

Bug reports, testing on hardware I don't own, and pull requests help just as much.
