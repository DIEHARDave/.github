# .github

Default community health files for [DIEHARDave](https://github.com/DIEHARDave)'s public repositories.

GitHub uses a file from this repo for any public repo that doesn't have its own copy:

| File | Purpose |
| --- | --- |
| `FUNDING.yml` | Sponsor button links (GitHub Sponsors, Ko-fi) |
| `SUPPORT.md` | Where to ask for help and how to support the projects |

A repo can override a file by adding its own copy, in its root or in its `.github/` folder.
